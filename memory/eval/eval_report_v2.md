# ReCollect Mock vs Real LLM 对比评估报告

> 评估时间：2026-08-06 15:30
> 评估数据：10 条 demo 笔记（含 2 广告 / 3 灰区 / 5 高价值）
> Mock provider：启发式关键词匹配 + 路由阈值
> Real provider：Qwen (qwen-plus) via OpenAI-compatible API

## 1. P2 筛选：三态决策准确率

### v1 prompt（原始）
| 指标 | Mock | Qwen v1 | Gold 期望 |
|---|---|---|---|
| keep | 5 | **0** | 5 |
| review | 3 | **10** | 3 |
| drop | 2 | **0** | 2 |
| 错误数 | 0 | **7** | - |
| 广告召回 | 100% | **0%** | - |

**问题**：v1 prompt 缺少明确三态判据，Qwen 倾向保守全标 review。

### v2 prompt（优化后）
| 指标 | Mock | Qwen v2 | Gold 期望 |
|---|---|---|---|
| keep | 5 | **5** | 5 |
| review | 3 | **3** | 3 |
| drop | 2 | **2** | 2 |
| 错误数 | 0 | **0** | - |
| 广告召回 | 100% | **100%** | - |

**修复方法**：P2 prompt v2 加入明确决策定义、判定顺序、路由规则、3-shot examples。

## 2. P3 归纳 + P5 审计

| 指标 | Mock | Qwen v2 |
|---|---|---|
| P3 归纳条数 | 8 | 8 |
| P5 抽检数 | 4 | 4 |
| 均审计分 | 0.800 | 0.986 |
| 保真度 | 1.0 | 0.988 |
| 覆盖度 | 0.775 | 0.975 |
| 分类准确 | 0.513 | 1.0 |
| 通过率(≥0.8) | 50% | 100% |

**发现**：
- Qwen P3 归纳质量明显优于 Mock（分类准确 1.0 vs 0.513）
- P5 审计分偏高（0.986），区分度不足——4 条审计中 3 条满分
- 原因：P3 和 P5 同为 qwen，存在自我确认偏差风险

**建议**：P5 换独立 provider（deepseek/kimi），实现审计与生成模型隔离。

## 3. P6 检索问答

### Per-query 检索结果
| Query | Gold | Mock top1 | Qwen top1 | 命中 |
|---|---|---|---|---|
| q1 副业方向 | n005 | n005 | n005 | ✅ |
| q2 上海落户 | n006 | n006 | n006 | ✅ |

**发现**：
- 三个 query 的 top1 都命中 gold，R@k=100%

- 这是**小数据集的正常现象**，不是 bug——扩到 100+ 条语料后 P@k 会自然提升

## 5. 结论与下一步

### 已解决
- ✅ P2 三态决策：v2 prompt 修复全 review 问题，0 错误
- ✅ P3 分类准确率：Qwen 1.0 vs Mock 0.513，真实 LLM 分类明显更准
- ✅ P6 召回：top1 全部命中 gold

### 待优化
1. **P5 审计模型隔离**：当前 P3/P5 同为 qwen，建议 P5 换 deepseek
2. **P5 区分度**：审计分集中在 0.95-1.0，需要 prompt 调优让审计更严格
3. **P6 精度**：需扩到 100+ 条语料 + 20-30 个 gold query 才能有效评估
4. **P6 回答质量**：当前用 mock 模板回答，应接入真实 LLM 生成
